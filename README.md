# zoel-content-assets (공개)

`zoel-content`(비공개) 파생물이 참조하는 공개 미디어 호스팅. GitHub Pages로 서빙되며 Meta(Threads·Instagram) API가 요구하는 공개 URL을 제공한다.

- `images/<slug>/<name>.png|jpg` — 카드·카루셀 이미지 (JPEG/PNG, 8MB 이하, 폭 320~1440px)
- `video/` — 짧은 영상은 Release asset(파일당 2GiB)로 올리고 여기엔 목록만 둔다
- 원고·큐·토큰은 절대 이 저장소에 두지 않는다 (공개 저장소)

URL 형식: `https://gai-cmd.github.io/zoel-content-assets/images/<slug>/<name>.png`
